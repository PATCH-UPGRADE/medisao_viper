# medisao_viper

The ARPA-H / VIPER channel API as a standalone, installable Django app. See
[`viper_channel/README.md`](viper_channel/README.md) for the design, the
settings seams a host project provides, and how to run the test suite.

Extracted from [medcrypt.ai](https://github.com/MedCrypt/medcrypt.ai)'s
`medisao` app so it can be independently owned and maintained.
